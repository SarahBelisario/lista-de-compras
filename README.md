# 🛒 Lista de Compras

Uma aplicação web responsiva e intuitiva para gerenciamento de listas de compras no dia a dia, desenvolvida com foco em design moderno, usabilidade e boas práticas de front-end.

---
🔗 **Acesse o projeto online:** [Lista de compras](https://lista-de-compras-nine-steel.vercel.app/)

## 🚀 Tecnologias Utilizadas

O projeto foi desenvolvido utilizando as seguintes tecnologias:

- **HTML5**
- **CSS3 (Design Tokens)**
- **JavaScript (ES6+)**

---

## ✨ Funcionalidades

- ➕ **Adicionar itens:** Permite adicionar novos produtos à lista de compras facilmente.
- 🗑️ **Remover itens:** Opção para excluir itens que não são mais necessários.
- ⚠️ **Alertas/Notificações:** Feedback visual interativo ao realizar ações na lista.
- 📱 **Layout Responsivo:** Adaptado para funcionar perfeitamente em telas de celulares, tablets e computadores.

---

## 🎨 Design Tokens

O CSS do projeto foi estruturado utilizando **Design Tokens** (variáveis CSS) para manter a consistência de:
- Cores de fundo e superfícies
- Tipografia e tamanhos de fonte
- Espaçamentos e bordas
- Estados de feedback e alertas
